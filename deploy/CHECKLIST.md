# چک‌لیست استقرار (به ترتیب؛ هر مرحله کامل نشد، مرحلهٔ بعد نه)

نسخهٔ برگشت: کد `820d612` (قبل از ممیزی رابط D-085) و فایل `before-update-*.zip` داخل `backups/`.

## الف) قبل از هر چیز
- [ ] مشخص شود پایگاه دادهٔ هاست PostgreSQL است یا SQLite (راهنمای نصب PostgreSQL می‌خواهد).
- [ ] بکاپ دستی از برنامهٔ زنده دانلود و روی کامپیوتر ذخیره شد.
- [ ] تمرین تبدیل واحد روی کپی موفق بود (`UNIT_CONVERSION.md` بخش ۱).

## ب) استقرار
1. [ ] کد جدید روی هاست (بدون دست‌زدن به `.env`، `media/`، `backups/`).
2. [ ] ترمینال cPanel: `pip install -r requirements.txt` سپس `python manage.py update` (خودش بکاپ می‌گیرد).
3. [ ] Restart در «Setup Python App».
4. [ ] تبدیل واحد زنده (`UNIT_CONVERSION.md` بخش ۲) — **بعد** از update، **قبل** از استفادهٔ روزانه.

## ج) کارهای بعد از استقرار
- [ ] **بکاپ زمان‌بندی‌شده (حیاتی):** cPanel ← Cron Jobs ← روزانه (مثلاً ۰۳:۰۰):
  `cd /home/USER/paper-plus && .venv/bin/python manage.py backup_db --keep 14`
  هفته‌ای یک بار یک فایل را از هاست به کامپیوتر خودتان ببرید (بکاپ روی همان هاست کافی نیست).
- [ ] **نرخ دلار:** اول یک بار دستی `python manage.py fetch_usd_rate` را در ترمینال بزنید؛ اگر اتصال خروجی بسته بود پیام خطا می‌دهد و فایل‌ها آسیب نمی‌بینند. اگر کار کرد، Cron هر ۳ ساعت:
  `0 */3 * * * cd /home/USER/paper-plus && .venv/bin/python manage.py fetch_usd_rate`
- [ ] **مشخصات شرکت:** مقادیر `COMPANY_*` در `.env` (نام قانونی، کد اقتصادی، شمارهٔ ثبت، شناسهٔ ملی، کد پستی، تلفن، نشانی، پاورقی) را پر کنید و Restart بزنید. **لوگو:** فعلاً حرف اول نام در یک کادر چاپ می‌شود؛ لوگوی واقعی نیاز به یک تصمیم و تغییر کوچک در قالب چاپ دارد (فایل لوگو را بفرستید).
- [ ] **HSTS:** فقط وقتی HTTPS روی دامنهٔ نهایی کاملاً درست است. در `.env`: `HSTS_SECONDS=300` ← Restart ← چند روز بدون مشکل ← `86400` ← بعد از چند هفته `31536000`. برگرداندنش بعد از مقدار بزرگ سخت است.
- [ ] **حذف `Product.unit`:** آخرین کار؛ فقط بعد از تبدیل روی **همهٔ** پایگاه‌ها و با یک بکاپ تازه (نیاز به تصمیم D-086 و مایگریشن).

## د) تست دستی روی سایت زنده (با دادهٔ آزمایشی که بعداً لغو می‌شود)
- [ ] فاکتور فروش: Enter در جستجوی کالا، تایپ رقم فارسی در تعداد/قیمت، نوار پایین چسبنده، ثبت.
- [ ] فاکتور فروش نسیه با سررسید + دریافت بخشی از آن.
- [ ] فاکتور خرید با کرایه بار.
- [ ] ثبت پرداخت کلی مشتری و پرداخت به تأمین‌کننده.
- [ ] پاس‌کردن و برگشت یک چک (با نام چک در تأیید).
- [ ] هزینه با حواله، چک و نسیه.
- [ ] چاپ یک فاکتور (فونت درست، بدون سرصفحهٔ مرورگر).
- [ ] یک بکاپ دستی از صفحهٔ «پشتیبان‌گیری» و دیدن اینکه دانلود می‌شود.
- [ ] نمایش در موبایل: داشبورد، فروش، انبار.
