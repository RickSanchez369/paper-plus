# تبدیل واحد کالاها (D-081) — دستور کار با ترمینال cPanel

**چرا حساس است:** کالاهایی که تا حالا «کارتنی» ثبت شده بودند باید به «بسته» تبدیل شوند. اجرای اشتباه، موجودی، لایه‌های FIFO و سود را خراب می‌کند.
**قاعده:** هیچ‌وقت اولین اجرا روی دادهٔ زنده نیست. اول روی یک کپی تمرین می‌کنیم.

## ۱. تمرین روی کپی (روی کامپیوتر خودتان، نه هاست)
1. از برنامهٔ زنده: منوی «پشتیبان‌گیری» ← «دانلود پشتیبان کامل». فایل zip را نگه دارید.
2. روی کامپیوتر یک پایگاه دادهٔ **خالی** بسازید، `python manage.py migrate` بزنید، سپس:
   `python manage.py restore_db مسیر/فایل.zip`
3. گزارش (فقط نمایش است، چیزی تغییر نمی‌کند):
   `python manage.py inventory_unit_report`
4. با Sina فایل `map.json` را بنویسید:
   `{"merge": {"SKU-کارتنی": "SKU-بسته‌ای"}, "pack_per_carton": {"SKU-بسته‌ای": 5}}`
   فقط کالاهایی که **واقعاً یک کالا** هستند ادغام می‌شوند؛ حدس نزنید.
5. آزمایشی (همه‌چیز را انجام می‌دهد و برمی‌گرداند):
   `python manage.py convert_units --map map.json --dry-run`
6. خروجی را بخوانید: جمع فاکتورها و موجودی باید **دقیقاً برابر** بماند. اگر نوشت «قیمت بر تعداد در کارتن بخش‌پذیر نیست»، اختلاف چاپ‌شده را با Sina ببینید؛ فقط اگر چند تومان گرد‌شدن قابل قبول بود `--allow-rounding` بزنید.

## ۲. اجرای زنده (فقط بعد از تمرین موفق و اجازهٔ Sina)
در ترمینال cPanel، داخل پوشهٔ پروژه و با محیط مجازی (`source .../bin/activate` که پنل «Setup Python App» نشان می‌دهد):
1. بکاپ تازه: `python manage.py backup_db` (فایل را از پوشهٔ `backups/` به کامپیوتر خودتان هم بیاورید).
2. همان آزمایشی: `python manage.py convert_units --map map.json --dry-run` — **خروجی باید با تمرین یکی باشد.**
3. اجرای واقعی: `python manage.py convert_units --map map.json`
4. ری‌استارت برنامه (دکمهٔ Restart در Setup Python App).
5. نگاه سریع: صفحهٔ انبار (موجودی کارتن + بسته)، یک فاکتور فروش قدیمی (جمع تغییر نکرده)، گزارش مالی همان ماه.

## ۳. شرط توقف
- خروجی آزمایشی با تمرین فرق دارد، جمع‌ها برابر نیست، یا خطا آمد: **اجرای واقعی نزنید.**
- بعد از اجرای واقعی چیزی غلط بود: برنامه را از `backups/` بازیابی کنید (راهنمای بازیابی در `UPDATING.md`) و تا بررسی، با نسخهٔ قبلی کار کنید.
- حذف `Product.unit` (آخرین کار) **فقط** بعد از اینکه تبدیل روی همهٔ پایگاه‌های داده انجام شد.
